# react-fullstack-capston-project
Frontend: 

Using React redux toolkit I have created this project:

Navigation bar: Products, Suppliers, Customers, Profile, Logout.
Customers page:

Title: Relationships – Customers.
Features: Search bar, filter dropdown, customer cards with name, role, email, and status (Active/Pending).
Suppliers page:

Title: Suppliers.
Features: Add Supplier button, supplier cards with name, location, status, and delete option.

Backend (Node.js + Express + MongoDB)
Handles CRUD operations for Suppliers and Customers.
Likely includes authentication (JWT, login flow mentioned in notes).
Middleware for logging requests and handling CORS (seen in .gitignore commit message).
MongoDB used for storing supplier/customer data.
This is an Operations Management Platform (OPS):
Manage suppliers (add/delete, track status and location).
Manage customers (search, filter, track relationships).
Provide a unified dashboard for business operations.
